# Plugin Members

> Halo 博客系统的成员管理插件，支持访客自助申请、QQ信息自动填充与智能分组。

## ✨ 特性

- **自助申请入口**：提供易于集成的弹窗 UI 组件，方便访客提交加入申请。
- **QQ 信息一键获取**：输入 QQ 号后，自动调用 API 获取并填充 QQ 昵称和头像。
- **智能分组匹配**：根据用户的 IP 归属地、学校、填写的地区等信息，智能匹配并自动选择所属地区分组。
- **后台审批管理**：管理员可在 Halo 后台查看、审批、拒绝成员申请，并管理成员分组。

## 📦 安装与使用

1. 下载最新版本的 `.jar` 插件包。
2. 在 Halo 后台的 **插件管理** 页面上传并启用该插件。
3. 在主题或页面中引入成员申请弹窗组件。

## 🛠️ 开发指南

本项目为标准的 Halo Java 插件包，包含前后端代码。

```bash
# 编译并构建插件包
./gradlew build

# 插件打包产物位于
# build/libs/plugin-members-x.x.x.jar
```
